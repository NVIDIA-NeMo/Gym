# genrm_hs4

Download preprocessed data from private GitLab (`genrm_hs4`, version `0.1.0`):

```bash
uv run --extra mlflow python -m benchmarks.genrm_hs4.prepare
```

Requires registry credentials in `env.yaml`.
See [GenRM evaluation](../../resources_servers/genrm_eval/README.md) for evaluation commands and scoring.
