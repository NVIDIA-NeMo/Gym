# SWE Atlas Codebase Q&A

The 124-task Codebase Q&A subset of [SWE Atlas](https://github.com/scaleapi/SWE-Atlas),
using `harness_agent` and the unchanged upstream rubric evaluator.

See the [resource server](../../resources_servers/swe_atlas_qa/README.md) for preparation,
harness selection, and evaluation. Benchmark data is downloaded by `prepare.py` and is not included in Gym.
