# ASB reports

Generated by:

```bash
python -m benchmarks.asb.reporting.report results/asb/*.jsonl \
  --out benchmarks/asb/reports/asb.md \
  --json-out benchmarks/asb/reports/asb.json
```

Tables follow the published ASB layout: one row per model, ASR and Refusal Rate for DPI,
OPI, Memory Poisoning, Mixed and PoT Backdoor, plus column averages. Each cell is the mean
of the per-attack-type rates, not a pooled rate over rows — Mixed ran three attack types
where the others ran five, and pooling would silently reweight them.

Read the coverage table alongside the headline numbers. A low ASR next to a high workflow
failure rate does not mean the model resisted the attack; it means it never produced a
plan, and was therefore never offered the attacker tool.

Denominators and the four disclosed deviations are in [`../METRICS.md`](../METRICS.md).
