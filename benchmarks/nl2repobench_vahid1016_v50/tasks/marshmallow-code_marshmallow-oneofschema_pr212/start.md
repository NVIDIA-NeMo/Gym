## marshmallow-oneofschema Project Introduction and Goals

marshmallow-oneofschema is a small extension library for marshmallow that supports schema (de)multiplexing for polymorphic data. It provides a `OneOfSchema` class — a subclass of `marshmallow.Schema` — that, when serializing an object, determines the object's type name via `get_obj_type()`, looks up a concrete schema in the user-supplied `type_schemas` mapping, dumps the object with that schema, and injects an extra field (by default `"type"`) holding the type name. Deserialization is the reverse: it reads the type field from the incoming data via `get_data_type()`, removes it (configurable), and loads the data with the matching concrete schema. The library also overrides `dump`, `load`, and `validate` so polymorphic (de)serialization works both singly and with `many=True`, aggregating per-item errors with their indices. The goal of this task is to reconstruct the package (two source files plus packaging metadata) so that `from marshmallow_oneofschema import OneOfSchema` works against the installed marshmallow 3.x and the project can be installed with pip.
