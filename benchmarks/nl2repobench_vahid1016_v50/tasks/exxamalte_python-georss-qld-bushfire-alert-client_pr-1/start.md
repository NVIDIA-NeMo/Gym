## QldBushfireAlertClient Project Introduction and Goals

This project implements `georss_qld_bushfire_alert_client`, a small Python library that provides convenient access to the Queensland (Australia) Bushfire Alert GeoRSS feed published by the Queensland fire services. It builds on the generic `georss_client` library (which is already installed in the environment, version 0.19) and specialises its feed, feed-entry, and feed-manager classes for the Qld Bushfire Alert feed:

- `QldBushfireAlertFeed` fetches and filters entries from the feed URL, supporting radius (km, around home coordinates) and category filters.
- `QldBushfireAlertFeedEntry` represents a single incident, exposing standard GeoRSS entry attributes plus the feed-specific `attribution` and alert `status` (e.g. "Patrolled", "Going", "Contained"), the latter extracted from the entry description with a regular expression.
- `QldBushfireAlertFeedManager` tracks feed entries across successive updates and reports new, updated, and removed entries via callbacks.

The package version is `"0.8"`, defined in a dedicated `__version__.py` module.
