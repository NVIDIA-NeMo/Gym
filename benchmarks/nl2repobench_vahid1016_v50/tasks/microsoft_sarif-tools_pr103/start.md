## sarif-tools Project Introduction and Goals

sarif-tools is a Microsoft command-line utility and Python library for working with SARIF (Static Analysis Results Interchange Format) files. Version 3.0.5 reads SARIF v2.1.0 files produced by static analysis tools, normalises their results (which vary widely in quality and structure between tools), and produces a variety of output formats: CSV, HTML, MS Word, emacs compilation-mode text, Code Climate JSON, plain-text summaries, trend charts, diffs between old and new analyses, and copies of SARIF data optionally augmented with `git blame` information or filtered by a YAML-based filter language.

The library exposes a Python API centred on `sarif.loader`, the `SarifFileSet`/`SarifFile`/`SarifRun` classes, and `IssuesReport`. The CLI entry point is the `sarif` script (also runnable as `python -m sarif`), with subcommands including `blame`, `codeclimate`, `copy`, `csv`, `diff`, `emacs`, `html`, `info`, `ls`, `summary`, `trend`, `upgrade-filter`, `usage`, `version` and `word`. Implementations must reconstruct the package from the description below; exact behavior of evaluation-referenced imports is documented in the API section.
