## sqlalchemy-trino Project Introduction and Goals

sqlalchemy-trino is a SQLAlchemy dialect for Trino (f.k.a. PrestoSQL), exposing the `trino://` URL scheme to SQLAlchemy. Its primary purpose is to let tools such as Apache Superset — as well as any SQLAlchemy application — query Trino engines using the trino-python-client DBAPI. The package registers itself as a SQLAlchemy dialect, adapts SQL compilation and type handling to Trino's language, wraps the trino client's DBAPI and exception surface, and implements dialect reflection and connection handling against Trino's `information_schema`. Target version: 0.4.0, supporting Trino 352 and higher.
