## pypinfo Project Introduction and Goals

`pypinfo` is a small CLI tool and Python library for viewing PyPI download statistics via Google BigQuery. It uses the public `bigquery-public-data.pypi.file_downloads` table. The package exposes roughly 6 small modules: a Click-based CLI that accepts a project name, optional PEP 440 version specifiers, and query "field" names; a query builder that generates standard SQL; helpers for parsing results into rows, adding percentage columns, adding download totals, tabulating (plain or Markdown), and JSON output; a credential store backed by TinyDB; a set of named field definitions mapped to BigQuery expressions; and a package entry point `python -m pypinfo`.

The goal of this reconstruction is to produce an importable, installable `pypinfo` package matching the documented behavior of version 23.0.0.
