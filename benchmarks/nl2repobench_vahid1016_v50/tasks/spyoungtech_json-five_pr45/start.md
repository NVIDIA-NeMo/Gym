## json-five Project Introduction and Goals

`json-five` is a Python library (import name `json5`, distribution name `json-five`) implementing the JSON5 specification. It provides a stdlib-`json`-like interface (`loads`, `load`, `dumps`, `dump`) plus an abstract model API that parses a JSON5 document into a node tree preserving comments, whitespace context, raw values, and tokens, enabling round-trip load/edit/dump workflows, linters, and formatters. It is built on the `sly` lexer/parser toolkit and the `regex` module. This specification reconstructs the library from the upstream source layout at version 1.0.0.post2.
