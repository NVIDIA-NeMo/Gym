## AIS-Tools Project Introduction and Goals

The `ais-tools` package (distributed as `ais-tools`, imported as `ais_tools`) is a set of
tools for encoding and decoding AIS (Automatic Identification System) messages transmitted
in NMEA / AIVDM sentence format. It builds on the installed `libais` decoder as a fallback,
adding a pure-Python transcoding engine (built on `bitarray` and `cbitstruct`) for message
types libais does not handle well, a fast C-extension module for NMEA checksum operations,
tagblock manipulation utilities, multi-sentence (multipart) message joining, a message
normalization pipeline, a benchmark suite, and a Click-based command-line interface
(`ais-tools`) with subcommands: `decode`, `encode`, `add-tagblock`, `update-tagblock`,
`join-multipart`, `benchmark`, and `cloud-stream`.

The goal of this reconstruction task is to produce a fully importable, installable
`ais_tools` package from this specification, matching the public API and observable
behavior described below.
