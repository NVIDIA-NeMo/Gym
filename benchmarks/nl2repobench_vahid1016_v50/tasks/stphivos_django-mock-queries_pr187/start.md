## Django Mock Queries Project Introduction and Goals

`django_mock_queries` is a library for mocking Django QuerySet functions in memory for unit testing. It lets tests exercise Django ORM-style code (filtering, aggregation, CRUD, field lookups, Q objects, slicing, iteration) without a database. It also provides DRF serializer asserts, relation mocking helpers, and database-connection mocking utilities so Django test runs can skip test-database creation entirely.
