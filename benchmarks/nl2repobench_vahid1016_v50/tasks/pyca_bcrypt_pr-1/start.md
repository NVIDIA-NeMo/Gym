## bcrypt Project Introduction and Goals

This project reconstructs `bcrypt`, the pyca password-hashing library (version 5.0.0). The package provides a small, well-defined API for hashing and verifying passwords with the bcrypt algorithm, generating salt strings with an adjustable logarithmic cost factor and version prefix, and deriving keys via the `bcrypt_pbkdf` KDF used by OpenSSH's private-key format.

The upstream project is a Rust extension module (`bcrypt._bcrypt`) built with PyO3 and setuptools-rust, re-exported through a thin pure-Python `bcrypt` package under `src/` layout. The observable public interface consists of four functions — `hashpw`, `checkpw`, `gensalt`, and `kdf` — plus a set of module metadata constants.

The goal of this task is to produce an importable, installable `bcrypt` package from scratch: the Python wrapper, the native (or equivalent) `_bcrypt` backing module, packaging metadata (`pyproject.toml` with a setuptools-rust extension definition), the `py.typed` marker, a README, and a MANIFEST.in. The implementation must behave per the bcrypt specification: modular crypt format (`$2a$`, `$2b$`, `$2y$`, `$2x$` prefixes), cost factors 4–31, the bcrypt-specific base64 alphabet with no padding, a 72-byte password limit enforced with `ValueError`, constant-time password comparison, and the `bcrypt_pbkdf` key derivation with its documented validation and warning rules.
