## ufomerge Project Introduction and Goals

ufomerge is a command-line utility and Python library that merges two UFO (Unified Font Object) source-format fonts into a single font. It takes glyphs from a "donor" UFO and merges them into a "target" UFO, handling glyph outlines, component closure, lib entries, kerning (with group handling), and OpenType layout rules — including the ability to "subset" the donor's feature file down to just the rules relevant to the selected glyphs, or to grow the glyph set by layout closure so ligatures and substitutions continue to work. It also scales the donor font when units-per-em differ, merges anchors of the dotted-circle glyph, and can be used in reverse to subset a UFO via `subset_ufo`.

This specification reconstructs the full `ufomerge` package (6 Python modules under `Lib/ufomerge/`) plus its packaging metadata, from scratch.
