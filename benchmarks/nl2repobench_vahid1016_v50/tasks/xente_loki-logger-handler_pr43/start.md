## loki-logger-handler Project Introduction and Goals

`loki-logger-handler` is a Python logging handler that ships log records to a (Grafana) Loki server in JSON format. It exposes a `logging.Handler` subclass, `LokiLoggerHandler`, that buffers formatted log lines, groups them into streams by label set, and periodically pushes them to Loki's HTTP push endpoint (`/loki/api/v1/push`) — optionally gzip-compressed and with basic-auth credentials or additional headers.

Key goals:

- Push JSON-formatted log lines (message, timestamp, process, thread, function, module, name, level, plus any logger "extra" fields).
- Support configurable static labels per handler, plus dynamic labels extracted from log record keys (`label_keys`).
- Support both the standard library `logging` module (via `LoggerFormatter`) and the third-party *loguru* library (via `LoguruFormatter`, using the handler's `write` hook or as a sink).
- Support Loki 3.0 structured metadata: static `loki_metadata` values, per-record metadata passed via an `extra={"loki_metadata": {...}}` key, and promotion of arbitrary record keys into metadata via `loki_metadata_keys`.
- Batch buffered lines into `Stream`/`Streams` payloads and flush them either on a fixed timeout interval or at interpreter exit.

The library is small (a single package with a `formatters` subpackage) and depends only on `requests`.
