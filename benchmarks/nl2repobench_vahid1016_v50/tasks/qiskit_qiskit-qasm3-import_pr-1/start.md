## qiskit-qasm3-import Project Introduction and Goals

`qiskit_qasm3_import` is a lightweight Python package that converts OpenQASM 3 programs into Qiskit `QuantumCircuit` objects. It is the basic, temporary importer used by Qiskit itself as an optional dependency: when installed, Qiskit's `qiskit.qasm3.load` / `qiskit.qasm3.loads` are thin wrappers around this package's `parse` function. The package parses an OpenQASM 3 string with the `openqasm3` reference parser (which is ANTLR-based via `antlr4-python3-runtime`), then walks the resulting AST with a visitor that builds a `QuantumCircuit` supporting qubit declarations, the `stdgates.inc` standard-library gates, custom gate definitions with modifiers, measurements, resets, barriers, aliases, classical registers, `input` parameters (as Qiskit `Parameter` objects), branching (`if`/`else`), `while` and `for ... in` loops, `break`/`continue`, hardware-qubit (`$N`) physical addressing, delay/box scopes (on sufficiently new Qiskit), and annotations (Qiskit 2.1+). Errors during conversion raise `ConversionError`, with source location prefixes when available. The goal of this task is to reconstruct the entire importable package plus packaging metadata from this specification alone.
