## GrowthBook Python SDK Project Introduction and Goals

This repo reconstructs the official GrowthBook Python SDK, a feature flagging and A/B testing library offering fully local evaluation (no network per check), deterministic variation assignment via FNV-1a hashing, MongoDB-style targeting condition evaluation, sticky bucketing, encrypted feature payloads, an in-memory feature cache with stale-while-revalidate and SSE auto-refresh, plus an async `GrowthBookClient` and a plugin system (tracking, request context). The final output is an importable, typed `growthbook` package (version 1.4.6) plus standard Python packaging metadata.
