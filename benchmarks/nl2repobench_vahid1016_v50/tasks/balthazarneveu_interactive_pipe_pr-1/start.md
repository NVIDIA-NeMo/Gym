## interactive_pipe Project Introduction and Goals

`interactive_pipe` is a Python library that lets developers build interactive image/signal-processing pipelines and automatically attach a graphical user interface to them without writing any GUI code. Users write plain processing functions ("filters"), declare which keyword arguments should become tunable parameters via tuples or `Control` objects, and combine filters into a pipeline function. A decorator then turns the pipeline into a live GUI backed by one of four backends: Qt (`gui="qt"`), matplotlib (`gui="mpl"`), Jupyter/ipywidgets (`gui="nb"`), or Gradio (`gui="gradio"`). Pipelines can also run headlessly for batch processing, and intermediate results can be cached in RAM for fast re-computation. The library additionally provides data objects (`Image`, `Curve`, `Audio`, `Table`, `Parameters`) with save/load/display helpers, a clean "context API" for sharing state between filters (`context`, `layout`, `audio`, `get_context()`), a panel system for organizing controls, and keyboard-driven controls.

This task reconstructs version 0.8.10 of the package from scratch.
