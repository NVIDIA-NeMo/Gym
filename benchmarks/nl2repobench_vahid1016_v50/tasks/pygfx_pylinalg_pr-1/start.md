## pylinalg Project Introduction and Goals

`pylinalg` is a small, pure-Python linear algebra utility library for graphics programming, maintained by the pygfx project. It provides NumPy-based helpers for working with vectors, quaternions, homogeneous transformation matrices, axis-aligned bounding boxes, and projection matrices. All functions follow a uniform API: positional input arguments followed by keyword-only `out` and `dtype` parameters, supporting broadcasting and in-place output. The library is used by pygfx (the Python visualization framework) for 3D math operations such as composing/decomposing transforms, building camera projections, look-at rotations, quaternion conversions, and coordinate-system conversions (spherical/euclidean).

The goal of this task is to reconstruct the complete importable `pylinalg` package (version 0.6.8) from this specification, along with its packaging metadata, so that `import pylinalg` works and all public functions behave as documented below.
