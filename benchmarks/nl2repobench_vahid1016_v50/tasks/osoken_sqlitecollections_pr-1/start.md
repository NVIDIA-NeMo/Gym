## sqlitecollections Project Introduction and Goals

`sqlitecollections` is a pure-Python library providing container types (`List`, `Set`, and `Dict`, and factory classes for them) whose contents are stored in an sqlite3 database rather than in RAM. Elements are automatically serialized (by default with pickle, protocol 3) when written and deserialized when read. The containers implement the `collections.abc` mutable sequence / mutable set / mutable mapping protocols and are largely drop-in compatible with the corresponding built-in `list`, `set`, and `dict`, differing mainly in that elements cannot be mutated in place. Because data lives on disk, containers support very large data even on memory-constrained machines, and a container created with an explicit `connection` (file path) and `table_name` can be reloaded later, restoring its previous contents instantly.

The goal of the reconstruction is to build an importable, installable Python (>= 3.7, running here on 3.11) package named `sqlitecollections` that exposes, at version 1.2.0:

- `sqlitecollections.List`, `sqlitecollections.Set`, `sqlitecollections.Dict`
- `sqlitecollections.ListFactory`, `sqlitecollections.SetFactory`, `sqlitecollections.DictFactory`
- `sqlitecollections.PicklingStrategy`, `sqlitecollections.SortingStrategy`
- module-level metadata: `__version__`, `__author__` ("osoken"), `__description__`, `__email__` ("osoken.devel@outlook.jp"), `__package_name__`.
- the internal modules `sqlitecollections.base`, `sqlitecollections.factory`, `sqlitecollections.dict`, `sqlitecollections.list`, `sqlitecollections.set`, `sqlitecollections.logger`, and the `py.typed` marker file.

3. `base.py` implements the shared foundation: a `PicklingStrategy(str, Enum)` with members `whole_table` and `only_file_name`; helper functions `sanitize_table_name(table_name, prefix)` (strip non-alphanumeric/non-underscore characters, generate a random name when empty, prefix the container type when the result starts with a digit, log a warning when the name changed), `create_random_name(prefix)` (`"<prefix>_<uuid4 with dashes stripped>"`), `is_hashable(x)` (`isinstance(x, collections.abc.Hashable)`), `create_temporary_db_file()` (an `NamedTemporaryFile` with prefix `sc_` and suffix `.db`), `create_tempfile_connection()`, and `tidy_connection(connection=None)` which returns `sqlite3.connect` of a temporary file when `None`, `sqlite3.connect(connection)` for a string, the connection itself for an `sqlite3.Connection`, and otherwise raises `TypeError`.
