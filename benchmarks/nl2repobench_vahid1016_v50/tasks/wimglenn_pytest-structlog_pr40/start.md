## pytest-structlog Project Introduction and Goals

pytest-structlog is a pytest plugin providing structured logging assertions for code using the `structlog` library. It exposes a pytest fixture named `log`, which is an instance of `StructuredLogCapture`. During a test, the plugin reconfigures structlog so that all log events emitted by any logger are captured into `log.events` (a list of event dicts) instead of being rendered/printed. Test code can then assert which events were logged, using helper methods like `log.has(...)` and factory methods like `log.info(...)` or by comparing the `EventList` against expected event dicts with subsequence-aware ordering operators.

Advanced configuration allows the user to choose which pre-existing structlog processors survive during tests (keep/evict mode), or to disable automatic processor selection entirely (`--structlog-explicit`). On test failure, captured structlog events are attached as a report section. A verbosity-dependent report shows which processors were kept or evicted at collection completion.
