## pydorado (dorado) Project Introduction and Goals

dorado is a Python package for simulating passive Lagrangian particle transport over flow fields from 2D shallow-water hydrodynamic models (e.g., DeltaRCM, ANUGA, Delft3D) using a weighted random-walk methodology. The distributed package name on PyPI is `pydorado`, while the importable package is `dorado`, version 2.7.0.

The package provides:

- A parameter class (`modelParams`) holding grid attributes (depth, stage, discharge, velocities, cell types, weighting parameters).
- A `Particles` class that validates parameters, computes D8 routing weights, seeds particle groups, and iteratively routes particles (single iteration, or iterating to a target travel time).
- Core Lagrangian walking routines: neighbor-window construction, weight computation, stochastic cell selection, steepest-descent routing, step distance and travel-time computation, boundary checks.
- Parallel routing via `multiprocessing`.
- Higher-level routines for automated steady/unsteady plotting animations, exposure-time distribution plots, travel-path drawing, and nourishment area/time heatmaps.
- Coordinate conversion helpers (geographic ↔ raster index; unstructured → gridded interpolation).
- Spatial analysis of exposure times over chunked domains with KDE-based percentile thresholds, MAD smoothing, and plotting.
- Example-data helpers that load bundled `.npz` arrays to construct ready-to-run example particles/parameters.
- Centralized logging with a `setup_logging` function and backward-compatible handling of a deprecated `verbose` flag.
