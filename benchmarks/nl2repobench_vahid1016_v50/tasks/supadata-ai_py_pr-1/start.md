## Supadata Project Introduction and Goals

Supadata is the official Python SDK for the Supadata API (https://supadata.ai), a service for extracting media data (transcripts, metadata, structured AI extraction) from YouTube, TikTok, Instagram, Twitter/X, and the open web. The SDK provides a single top-level `Supadata` client that authenticates with an API key, exposes namespaced sub-clients (`youtube`, `web`, `extract`), converts JSON responses (including camelCase keys) into typed dataclass objects, and raises a structured `SupadataError` exception on API errors. The goal of this reconstruction is to produce an importable, installable `supadata` package (version 1.6.0, MIT) that faithfully reimplements the public API and observable behavior described below, including a deprecated legacy YouTube API surface kept for backward compatibility.

2. `supadata.errors` defines `SupadataError`, a dataclass that also subclasses `Exception`, with fields `error: str`, `message: str`, `details: str`, and `documentation_url: Optional[str] = None`. Its `__str__` joins the message and, when non-empty, `error: …`, `details: …`, and `documentationUrl: …` segments with `" | "`.
3. `supadata.client` defines the `Supadata` class: constructor takes `api_key` (required) and `base_url` (default `"https://api.supadata.ai/v1"`). It creates a `requests.Session` with headers `x-api-key`, `Accept: application/json`, and `User-Agent` of the form `Supadata-Python-SDK/<version>` where version comes from `importlib.metadata.version('supadata')`. It initializes namespaces `self.youtube = YouTube(self._request)`, `self.web = Web(self._request)`, and `self.extract = _Extract(self._request)` where `_request` is the internal request method.
4. The internal `_request(method, path, **kwargs)` method requests `{base_url}{path}` using the session, and: (a) if a transcript-path request returns HTTP 206, it parses the snake_cased JSON body and raises `SupadataError(**error_data)` if an `error` key is present, otherwise raises `SupadataError(error="transcript-unavailable", message="No Transcript", details="No transcript available")`; (b) on `raise_for_status()` HTTP errors, it attempts to parse the JSON error body (snake_cased) and raise `SupadataError(**error_data)` from the original exception, re-raising the HTTPError if the body cannot be parsed; (c) on success it returns the parsed JSON with all dictionary keys (recursively, including inside lists) converted from camelCase to snake_case via a helper such as `_camel_to_snake`.
5. `Supadata.metadata(url)` performs `GET /metadata` with `params={"url": url}` and returns `Metadata(**response)`.
6. `Supadata.transcript(url, lang=None, text=False, chunk_size=None, mode="auto")` performs `GET /transcript` with query params including `url` and `mode`, plus `lang` (if given), `text` (as the lowercase string `"true"` when true), and `chunkSize` (if given). If the response contains `job_id`, it returns `BatchJob(job_id=...)`; otherwise it returns `Transcript(**response)`.
