## py360convert Project Introduction and Goals

py360convert is a pure-Python library for converting between panoramic image projections. It converts between equirectangular panoramas, cubemaps (in `dice`, `horizon`, `list`, and `dict` layouts), and planar perspective images. The implementation is vectorized with NumPy and SciPy; if OpenCV is available it is used automatically to accelerate resampling (several-times speedup), otherwise SciPy's `map_coordinates` is used. The package also ships a `convert360` command-line tool for performing these conversions on image files. The library depends only on numpy, scipy, and pillow.
