## kaldialign Project Introduction and Goals

`kaldialign` is a small Python package exposing Kaldi's Levenshtein edit-distance, alignment, and bootstrap WER confidence-interval computations. The original project wraps Kaldi C++ code with pybind11 into an extension module named `_kaldialign`, and provides a pure-Python package `kaldialign` that maps arbitrary hashable symbol sequences (strings, lists of strings, lists of ints) onto integer sequences before invoking the compiled core. The motivation (per the project README) is that Levenshtein implementations differ subtly between tools; wrapping Kaldi's own algorithms guarantees score-identical behavior with Kaldi.

This reconstruction task asks you to rebuild the complete library from this specification: a pure-Python package `kaldialign` with the functions `align`, `edit_distance`, and `bootstrap_wer_ci`, plus the native/underlying `_kaldialign` module they depend on, and any packaging metadata needed to make the package importable. The environment does not include a C++ toolchain, pybind11, or cmake; the build metadata of the original project (setup.py driving a cmake build) must therefore be adapted so that the package installs and imports successfully with the available tooling. The observable numerical and statistical behavior must match the original C++ implementation exactly, including its exact pseudo-random number semantics for the bootstrap functions, so special care is needed there (described below).

2. The package must also provide, at import time, a module named `_kaldialign` (importable from the same site-packages / sys.path location) exposing the low-level integer-sequence API used internally by `kaldialign/__init__.py`. Because no compiler or pybind11 is available, implement `_kaldialign` as pure Python that faithfully reproduces the original C++ algorithms; the Python wrapper code must be able to `import _kaldialign` and call its functions, mirroring the original design.
3. `_kaldialign.edit_distance(a, b, sclite_mode=False)`: takes two lists of non-negative ints and returns a dict with keys `ins`, `del`, `sub`, `total`, holding the insertion, deletion, substitution, and total error counts of `hyp` (`b`) relative to `ref` (`a`). Implement Kaldi's `LevenshteinEditDistance` dynamic program: costs are 1/1/1 (ins/del/sub) normally, or 3/3/4 when `sclite_mode` is true; `total` counts the number of errors (ins+del+sub) along the minimum-cost path; tie-breaking must match Kaldi's recurrence (prefer substitution when strictly smallest, then deletion when strictly smaller than insertion, otherwise insertion).
4. `_kaldialign.align(a, b, eps_symbol, sclite_mode=False)`: takes two lists of ints, an integer eps symbol that is asserted not to occur in either sequence, and returns a list of `(int, int)` pairs giving the minimum-cost alignment; a pair `(eps_symbol, x)` marks an insertion, `(x, eps_symbol)` a deletion, unequal non-eps symbols a substitution. Backtracking must match Kaldi's `LevenshteinAlignment`: prefer substitution on strict ties, deletion when `del < ins`, otherwise insertion; produce the alignment in forward (time) order.
5. `_kaldialign._get_edits(refs, hyps)`: for two equal-length lists of lists of ints, returns a list of `(edit_distance_total, ref_length)` pairs, one per sentence, where the edit distance is computed with unit costs (no sclite mode).
6. `_kaldialign._get_boostrap_wer_interval(edit_sym_per_hyp, replications=10000, seed=0)`: implements the Bisani–Ney bootstrap. It draws, for each of `replications` iterations, `len(edit_sym_per_hyp)` indices uniformly at random with replacement from the range `[0, len-1]`, sums the selected `(errors, nsym)` pairs into a replication WER `errors/nsym`, and returns a tuple `(mean, interval)` where `mean` is the average of replication WERs and `interval` is `1.96 * sqrt(mean_of_squares - mean^2)` (or `0.0` when the variance term is non-positive). **Critical:** the random stream must reproduce C++ `std::mt19937{seed}` combined with libstdc++'s `std::uniform_int_distribution<>(0, n-1)` semantics exactly, in the same nested-loop order as the original C++ code, so that identical seeds yield bit-identical floating-point results to the original library. Implement the C++ mt19937 generator (32-bit, parameterization of the standard MT19937) and libstdc++'s uniform integer distribution algorithm (which consumes raw 32-bit outputs and, when the range does not divide the word size, uses rejection sampling against a power-of-two-scaled bound) in Python. Double precision accumulation order must match the C++ code.
7. `_kaldialign._get_p_improv(edit_sym_per_hyp, edit_sym_per_hyp2, replications=10000, seed=0)`: uses a fresh `std::mt19937{seed}` with the same distribution to sample indices in the same loop order; for each replication it sums `errors1[selected] - errors2[selected]` over all sentences; it counts a replication as an "improvement" when that sum is strictly greater than 0 and returns `improvements / replications` as a double.
8. `edit_distance(ref, hyp, sclite_mode=False)` in the Python package: maps the symbols of `ref` and `hyp` jointly to ints via `sorted(set(ref) | set(hyp))` (so symbol-to-int assignment is deterministic), calls `_kaldialign.edit_distance`, then augments the result dict with `ref_len` (length of the int-mapped ref) and `err_rate` = `total / ref_len`, with `err_rate` being `0.0` if both `total` is 0 and `ref_len` is 0, `inf` if `total > 0` and `ref_len == 0`, and a normal float otherwise. Returns keys `ins`, `del`, `sub`, `total`, `ref_len`, `err_rate`.
