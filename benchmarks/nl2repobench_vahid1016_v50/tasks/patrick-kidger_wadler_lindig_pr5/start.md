## wadler_lindig Project Introduction and Goals

`wadler_lindig` is a tiny, zero-dependency Wadler–Lindig pretty-printer for Python. It offers an alternative to the built-in `pprint` module that consumes less horizontal space: instead of breaking long lines at the right-hand margin, it lays out nested structures vertically with indentation, in the style of Wadler's "A prettier printer" (1998) and Lindig's "Strictly Pretty" (2000).

Key goals:

- Provide `pprint` (to stdout), `pformat` (to a string), and `pdiff` (a line diff between two strings) for day-to-day pretty-printing of arbitrary Python objects.
- Provide the core Wadler–Lindig document algebra — `TextDoc`, `BreakDoc`, `ConcatDoc`, `NestDoc`, `GroupDoc`, with a common `AbstractDoc` base offering `+`, `.nest()`, and `.group()` shorthands — plus `pformat_doc` to lay out a document to a given width.
- Provide `pdoc`, which converts any Python object into a document, understanding lists, tuples (including named tuples), dicts, sets, frozensets, `functools.partial`, plain functions, dataclass instances, typing objects (generic aliases and unions), and NumPy/PyTorch/JAX arrays (summarised concisely, e.g. `f32[2,3](numpy)`).
- Support customisation via a `__pdoc__(self, **kwargs) -> None | AbstractDoc` protocol on user types and via a `custom` callable argument.
- Support ANSI escape codes: `ansi_format` to add colours/bold, `ansi_strip` to remove codes; the layout engine ignores ANSI codes when measuring widths.
- Handle multi-line unbroken text, guard against infinite recursion with seen-object id tracking, and keep the implementation extremely small (the core algorithm is under 80 lines).
