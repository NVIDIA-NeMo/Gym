## pytest-cookies Project Introduction and Goals

**pytest-cookies** is a pytest plugin providing a `cookies` fixture that wraps the cookiecutter API to generate projects from cookiecutter templates during tests. It lets template authors verify their templates work as expected, captures cookiecutter failures into an inspectable `Result` object instead of crashing the test, and automatically cleans up generated output directories after each test unless the user asks to keep them. The plugin registers itself via the `pytest11` entry point and adds command-line options for choosing a template directory and keeping baked projects.
