## Lavatory Project Introduction and Goals

Lavatory is a command-line tool for managing Artifactory retention policies. It lets teams define per-repository retention rules as small Python plugin modules (using `pluginbase`), then apply those policies against a JFrog Artifactory instance to delete (purge) old artifacts. The tool supports dry-run mode, per-repository and per-repo-type targeting, artifact statistics reporting, and space-reduction performance reporting after a purge run.

The goals of this reconstruction are:

1. Provide an importable Python package `lavatory` (src-layout) with a Click-based CLI exposing the commands `purge`, `stats`, `policies`, and `version`.
2. Implement an `Artifactory` utility class wrapping the `party` library for storage info, AQL searches, property lookups, deletion, and moves.
3. Implement plugin discovery via `pluginbase`, with a built-in `default` policy plus support for user-supplied extra policy directories.
4. Implement credential loading from environment variables with descriptive custom exceptions.
