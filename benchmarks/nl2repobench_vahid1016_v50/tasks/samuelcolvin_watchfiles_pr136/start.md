## watchfiles Project Introduction and Goals

`watchfiles` is a simple, modern, high-performance file-watching and code-reload library for Python. It recursively watches one or more filesystem paths and yields sets of changes (added / modified / deleted file paths) as files change, using low-level OS file-system notifications where available (the original project delegates these to the Rust `notify` crate via a PyO3 extension named `watchfiles._rust_notify`). On top of the raw watcher it provides:

- `watch`: a synchronous generator yielding change sets.
- `awatch`: an asynchronous (anyio-based) generator yielding change sets.
- `run_process` / `arun_process`: run a Python function or shell command in a subprocess and restart it whenever watched files change.
- A CLI (`watchfiles` console script) that wraps `run_process` with filtering and verbosity options.
- A filter framework (`BaseFilter`, `DefaultFilter`, `PythonFilter`) that decides which change events are surfaced.
- A `Change` enum describing the kind of change.

This is a reconstruction task: the workspace starts with only this specification, and you must write the entire importable package plus packaging metadata, including the `watchfiles._rust_notify` backend module (a compiled Rust extension in the original project; an equivalent native backend must be produced as described below).
