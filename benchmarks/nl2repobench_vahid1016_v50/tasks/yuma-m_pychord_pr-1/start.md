## PyChord Project Introduction and Goals

PyChord is a pure-Python library for handling musical chords. It can parse chord symbol strings (such as `"C"`, `"Am7"`, `"F#m7-5/A"`), compute the component notes of a chord, transpose chords and chord progressions, build chords from scale degrees, analyze sets of notes to identify matching chords, and manage an extensible registry of chord qualities. This task is to reconstruct the `pychord` package (version 1.3.2) from this specification, producing an importable, installable library with no runtime dependencies beyond the Python standard library.
