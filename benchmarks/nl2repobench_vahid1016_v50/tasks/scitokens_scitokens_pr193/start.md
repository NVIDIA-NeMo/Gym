## scitokens Project Introduction and Goals

SciTokens is a reference implementation library for the SciTokens capability-based authorization token format, built on top of PyJWT and the `cryptography` library. It provides a safe, high-level interface for creating, signing, serializing, deserializing, verifying, validating, and enforcing JSON Web Token (JWT)-based SciTokens, along with a persistent cache of issuer public keys, URL path-normalization helpers, an optional demo-token generator, an ini-file based configuration system, and command-line tools for token and key administration.
