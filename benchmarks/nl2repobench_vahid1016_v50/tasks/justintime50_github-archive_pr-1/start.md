## GitHub Archive Project Introduction and Goals

GitHub Archive is a Python CLI tool and library that concurrently clones, pulls, or forks GitHub repositories and gists from users, organizations, and starred-repo lists to build a local "GitHub archive". It supports authenticated and unauthenticated use, per-user/org/gist/star lists, include/exclude/language filters, HTTPS vs SSH clone URLs, configurable timeouts and thread counts, custom GitHub Enterprise base URLs, and configurable logging to console and rolling log files. The goal of this reconstruction is a fully importable, installable `github-archive` package matching the public API described below.
