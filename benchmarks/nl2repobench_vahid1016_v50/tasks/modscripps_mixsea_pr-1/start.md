## mixsea Project Introduction and Goals

mixsea is a Python library of ocean mixing parameterizations: tools to estimate turbulent dissipation and diapycnal diffusivity from CTD and LADCP profile data. It provides two families of estimates: (1)Thorpe-scale-based overturning analysis, and (2) shear/strain spectral parameterizations based on the Gregg–Henyey–Polzin framework with the Garrett–Munk internal wave spectrum as reference. The library is built on numpy, scipy and the Gibbs SeaWater (gsw) TEOS-10 toolbox, and is distributed under an MIT license.

The goal of this task is to reconstruct the importable `mixsea` package from scratch: implement the four source modules (`helpers`, `nsq`, `overturn`, `shearstrain`), the package `__init__`, and modern pyproject-based packaging metadata, such that `import mixsea` works and all public functions behave as specified.

## Natural Language Instructions (Prompt)

1. Create a Python package named `mixsea`, laid out in a `src/` layout (`src/mixsea/`), with modules `__init__.py`, `helpers.py`, `nsq.py`, `overturn.py` and `shearstrain.py`.
2. `__init__.py` must import the submodules `nsq`, `overturn` and `shearstrain` as attributes, define `__all__ = ["overturn", "shearstrain", "nsq"]`, and set `__version__` via `importlib.metadata.version("mixsea")` (version is declared in packaging metadata, currently 0.2.0).
3. `helpers.py` provides utility functions used by the parameterizations: `denan(data)` (return non-NaN data and their indices), `calc_shear(u, depth)` (vertical shear via first differences interpolated back to `depth` midpoints), `extrapolate_data(data)` (fill trailing NaNs with the last finite value), `psd(...)` (power spectral density adapted from Jen MacKinnon, supporting fft types 'p' periodic, 'c'/'s' cosine/sine extension, and 't' windowed Welch periodogram with optional `tser_window`/`tser_overlap`; returns `Pcw, Pccw, Ptot, omega` splitting spectra into clockwise/counter-clockwise components, with detrending by default and a hamming window), `read_testfile(filename)` (read a CSV with a `#`-commented header line into a dict keyed by variable names), and `read_ctd_testfile(path=None)` / `read_ladcp_testfile(path=None)` wrappers.
4. `nsq.py` provides buoyancy-frequency routines: `nsqfcn(s, t, p, p0, dp, lon, lat)` which low-pass filters t/s/p (Hanning filter tuned to `dp`), interpolates onto a regular pressure grid, and uses TEOS-10 potential density differences to return `n2, pout` (returning NaN when filtered pressure is non-monotonic); and `adiabatic_leveling(P, S, T, lon, lat, bin_width=100.0, order=1, return_diagnostics=False, cap=None)` which fits polynomials of specific volume in sliding pressure bins per Bray & Fofonoff (1981), supporting `order` 1–3 and `cap` in {None, 'left', 'right', 'both'} to exclude partially filled end bins, returning `N2_ref` (optionally with fit coefficients).
5. `overturn.py` implements Thorpe-scale mixing estimates. Main entry points: `nan_eps_overturn(depth, t, SP, **kwargs)` which removes NaNs, calls `eps_overturn` on the finite subset, and re-inserts NaNs (also re-inserts NaNs into 1-D diagnostic arrays of matching length when `return_diagnostics=True`); and `eps_overturn(depth, t, SP, lon=0.0, lat=0.0, dnoise=5e-4, alpha=0.95, Roc=0.2, background_eps=np.nan, use_ip=False, N2_method='teos', overturns_from_t=False, pbinwidth=1000, EOS='gsw', linear_EOS_params=dict(rho0=1025, a=2e-4, b=7e-4, SP0=35, t0=15), return_diagnostics=False)` which computes dissipation `eps = alpha² · Lt² · N2^1.5` per overturning patch, with validation errors for non-monotonic depth, mismatched sizes, and invalid `N2_method`/`EOS` combinations.
6. Within `eps_overturn`: a scalar `SP` is broadcast to profile length; pressure is derived from depth via gsw; density uses TEOS-10 potential density binned over `pbinwidth` reference pressures (or the `linear` EOS via `pot_rho_linear`); overturns may be diagnosed from density or from temperature (`overturns_from_t`, with sign flip since temperature decreases downward); an optional intermediate profile (`use_ip`) preconditions the data; buoyancy frequency per patch is computed by `N2_method` in {'teosp1', 'teos', 'endpt', 'bulk'}; patches with `Ro` below `Roc`, negative N², or noise-level density differences are flagged and removed from the returned `eps`/`N2`, which are otherwise NaN (or `background_eps` where NaN).
7. `overturn.py` also exposes the building blocks: `pot_rho_linear(SP, t, rho0=1025, a=2e-4, b=7e-4, SP0=35, t0=15)`, `thorpe_scale(depth, q, dnoise)` (returns Lt, thorpe_disp, q_sorted, noise_flag, ends_flag, Ro, idx_patches, idx_sorted, Lp; raises ValueError if the profile is globally unstable or depth is non-monotonic), `find_overturns(q)` (cumulative-sum-of-sorting-index-differences method returning sorting indices and (N,2) patch indices), `intermediate_profile_topdown(q, acc, hinge)`, `intermediate_profile(q, acc=5e-4, hinge=1000, kind='down')` with kind prefix matching 'up'/'do'/'av', and `contiguous_regions(condition)`.
8. `shearstrain.py` implements the shear/strain parameterization. Main entries: `nan_shearstrain(depth, t, SP, lon, lat, ladcp_u=None, ladcp_v=None, ladcp_depth=None, **kwargs)` (NaN-aware wrapper that drops NaNs in CTD and LADCP inputs and re-dispatches to `shearstrain`) and `shearstrain(depth, t, SP, lon, lat, ladcp_u=None, ladcp_v=None, ladcp_depth=None, m=None, depth_bin=None, window_size=None, m_include_sh=np.arange(4), m_include_st=np.arange(4), ladcp_is_shear=False, smooth='AL', sh_integration_limit=0.66, st_integration_limit=0.22, window='hamming', return_diagnostics=False)` which raises ValueError if NaNs are present in CTD or LADCP data.
9. Inside `shearstrain`: lon/lat are averaged to scalars; Coriolis parameter comes from gsw; velocity is converted to shear unless `ladcp_is_shear`; default wavenumber vector is `wavenumber_vector(w=300)` (radial wavenumbers from 2π/300 to 2π/10 m); default depth bins are `np.arange(75, max(depth), 150)` with the user-supplied `window_size`; a smooth N² reference is computed either by `strain_adiabatic_leveling` (`smooth='AL'`, adiabatic leveling with bin_width 300, order 2, cap 'both') or `strain_polynomial_fits` (`smooth='PF'`, order-2 polynomial per window); shear and strain spectra per window use `helpers.psd` with ffttype 't', compensated for first differencing by `H = sinc(m·dz/2π)²`, then interpolated onto `m`; cutoff wavenumbers come from `find_cutoff_wavenumber` using cumulative-trapezoid variance limits; ε is computed via `eps_shearstrain` (or `eps_strain` with a fixed shear/strain ratio Rw = 3), GM variances via `gm_shear_variance`/`gm_strain_variance` (`N0=5.24e-3`, `b=1300`, `jstar=3`, `E0=6.3e-5`, `eps0=7.8e-10`, `Gam0=0.2`); diffusivity uses `diffusivity(eps, N, Gam=0.2)`; Rw below 1.01 is clipped to 1.01 for the aspect-ratio correction; if no LADCP data are given, only the strain-only solution is returned.
10. `shearstrain.py` additionally exposes the helpers listed above plus `aspect_ratio_correction_shst(Rw)`, `aspect_ratio_correction_st(Rw)`, `latitude_correction(f, N)` (Gregg et al. 2003 latitudinal term with `f30 = gsw.f(30)`, `N0 = 5.24e-3`), and `eps_shearstrain(...)`/`eps_strain(...)`.
