# FLEURS language identification

Spoken language identification on the FLEURS test set: the model hears a clip and answers with one locale label
(top-1 accuracy).

- Data: [`google/fleurs`](https://huggingface.co/datasets/google/fleurs) `test` split (one transcript TSV and one audio
  tarball per locale), revision `70bb2e84b976b7e960aa89f1c648e09c59f894dd`. Paper: Conneau et al., 2022.
- License: CC-BY-4.0 (dataset card: "All datasets are licensed under the Creative Commons license (CC-BY)").
- Preparation checks each TSV (field count, safe unique WAV names, released clip count) and that each tarball holds
  exactly the clips its TSV lists, then writes 16-bit 16 kHz WAV files. One tarball per locale is downloaded and
  removed after extraction (the largest is 1.0 GB; all 102 are 50.7 GB, the 36-locale subset 16.5 GB); the clips take
  about as much.
- Default: **all 102 locales (77,810 clips)**; the prompt lists the labels in locale-code order, generated by
  `prepare()` into each row's source prompt, and the answer must match the reference label exactly (`zh_cn` is graded
  as `cmn_hans_cn`). A 36-locale subset (28,033 clips, `LOCALES_36`, set name `subset_36`) is also available:
  `ar_eg bg_bg cmn_hans_cn hr_hr cs_cz da_dk nl_nl en_us et_ee fil_ph fi_fi fr_fr de_de el_gr he_il hi_in hu_hu id_id
  it_it ja_jp ko_kr lv_lv lt_lt mt_mt pl_pl pt_br ro_ro ru_ru sk_sk sl_si es_419 sv_se th_th tr_tr uk_ua vi_vn`, and the
  prompt lists exactly these labels in this order. Accuracy over 102 locales is not comparable with the 36-locale number:

  ```bash
  gym eval prepare --benchmark fleurs_lid +prepare_script_args.languages=subset_36
  ```

  `languages` also takes a list (`'+prepare_script_args.languages=[ar_eg,en_us]'`; the prompt follows the given
  order). Smoke runs: `+prepare_script_args.max_samples_per_locale=5` (the tarballs are still downloaded in full) or
  `max_samples_per_profile=20` (the first clips, in locale order), usually with `languages=`.
- Requests allow 16 output tokens.
- Metrics (`audio/fleurs-lid/pass@1/*`): `accuracy_micro` over all clips, `accuracy_macro` over the locales present,
  `num_locales`, `accuracy::<locale>` and `accuracy_group::<group>`; each locale also has its own
  `audio/fleurs-lid-<locale>/pass@1/*`.
- Run: see the [audio_eval README](../../resources_servers/audio_eval/README.md#preparing-and-running-an-audio-benchmark).
