NeMo Gym provides two independent observability features:

| Feature | Use it to | Enable with |
| --- | --- | --- |
| Rollout evidence | Inspect model calls, agent activity, and saved trajectory health | `observability_enabled` and `model_call_capture_dir` |
| OpenTelemetry | Trace requests across services and monitor runtime metrics and logs | `telemetry.enabled` or `NEMO_GYM_OTEL_ENABLED=1` |

Each feature has its own configuration. You can enable either or both.
