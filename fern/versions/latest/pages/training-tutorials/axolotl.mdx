# Training with Axolotl

Axolotl's `NemoGymPlugin` uses one or more NeMo Gym environments as reward sources for GRPO training. It supports single-turn verification, multi-turn agent rollouts, and multi-environment training. In single-turn mode, it scores generated completions through a NeMo Gym resource server's `/verify` endpoint. In multi-turn mode, it delegates rollout orchestration to a NeMo Gym agent server through `/run`.

With automatic setup enabled, the plugin can clone NeMo Gym, create its Python environment, start the configured NeMo Gym services, and load the specified datasets.

The integration is developed and maintained by Axolotl. Refer to Axolotl's integration guide for currently validated models, versions, and training configurations.

## Prerequisites

- An Axolotl installation and hardware supported by the selected training configuration
- A compatible NeMo Gym checkout and training dataset

<Warning>
The Sudoku examples require a generated dataset; `train_mini_sudoku.jsonl` is not bundled with NeMo Gym. See Gym's [Reasoning Gym dataset preparation instructions](https://github.com/NVIDIA-NeMo/Gym/tree/main/resources_servers/reasoning_gym#dataset-prep).

With [Axolotl `4a62cbcab455`](https://github.com/axolotl-ai-cloud/axolotl/commit/4a62cbcab455fab978577b14d44ff29d99df6c49) and [NeMo Gym `bedf56450097`](https://github.com/NVIDIA-NeMo/Gym/commit/bedf5645009751591a17747bcf7a3b2b172f4708), generated Mini Sudoku data passed through Axolotl's dataset loader and reward function to a running Gym verifier. A correct answer received reward 1 and an invalid answer received reward 0. A reduced CPU run with TRL `1.14.1` and `HuggingFaceTB/SmolLM2-135M-Instruct` also completed two single-turn GRPO steps and saved a checkpoint. It used the `datasets` and `trl.reward_funcs` entries from Axolotl's [single-turn configuration](https://github.com/axolotl-ai-cloud/axolotl/blob/4a62cbcab455fab978577b14d44ff29d99df6c49/src/axolotl/integrations/nemo_gym/README.md#3-single-turn-training-simplest--no-agent-server-needed); the standalone Sudoku example omits these entries. This validates a small single-turn training run. The original GPU example, multi-turn rollouts, and training quality remain unvalidated.
</Warning>
