# Harbor Task Folders

A task folder holds one task in the [Harbor](https://github.com/harbor-framework/harbor) format: `task.toml`, and
usually `instruction.md`, `environment/`, `tests/` and `solution/`. The task carries its own environment and verifier,
and the `harbor` Environment Server runs it, so no Resources Server takes part. See
[Two kinds of tasks](/main/data#two-kinds-of-tasks) to decide whether task folders fit your tasks.

lists which harnesses run task folders. [Harbor Environment Server](/main/agent-interactions/harbor) explains how an
episode runs.
