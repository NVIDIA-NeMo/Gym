A task folder holds everything one task needs: the instruction, the container the agent works in, the tests that score
it and, optionally, a reference solution. Because each task brings its own environment and tests, there's no server to
write. Task folders use the Harbor task format, so tasks written for Harbor also run in Gym, within the subset Gym
supports.

Tasks that share one verifier and toolset, such as math, instruction following or tool calling, fit
[JSONL Datasets](/main/data/jsonl) better.

## Start here

[Author Task Folders](/main/data/task-folders/harbor-tasks) takes you from an empty folder to a working task: scaffold
a dataset, write a task, validate it with the oracle and run an agent. If you already use Harbor, start at
[Coming from Harbor](/main/data/task-folders/harbor-tasks#coming-from-harbor).
