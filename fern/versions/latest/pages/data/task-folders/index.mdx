A task folder holds everything one task needs: the instruction, the container the agent works in, the tests that score
it and, optionally, a reference solution. Because each task brings its own environment and tests, there's no server to
write.

Tasks that share one verifier and toolset, such as math, instruction following or tool calling, fit
[JSONL Datasets](/main/data/jsonl) better.
