Reference for NeMo Gym version compatibility with supported training frameworks.

<Info>
The standalone NeMo Gym image and NeMo RL training images are separate artifacts with independent release
schedules. Use `nvcr.io/nvidia/nemo-gym` to run Gym itself. Use a tested `nvcr.io/nvidia/nemo-rl` pairing
when a NeMo RL recipe requires the training framework and Gym in the same image.
</Info>

---

## Standalone NeMo Gym Container

Published NeMo Gym release images use the same tag as the Gym release. For example:

```bash
docker pull nvcr.io/nvidia/nemo-gym:v0.5.1
```

Replace `v0.5.1` with the release you need after its tag appears in the
[NeMo Gym NGC catalog](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-gym/tags). This rule applies
to future releases, so this page does not maintain a row for every standalone Gym image.

The existence of a standalone Gym image does not mean that a NeMo RL image bundles the same Gym version.

## NeMo RL Training Containers

The following table lists tested NeMo RL pairings. It is not a list of all NeMo Gym releases. NeMo Gym and
NeMo RL release independently, so a Gym version can have a standalone image without appearing here.

Match the container to your **model recipe**, not only your NeMo Gym version. For example, the
[NeMo RL GRPO](/tutorials/training-tutorials/nemo-rl-grpo) tutorial trains Nemotron Nano 9B v2 and uses the
Nano NGC container from the v0.1.1 row below—not the v0.3.0 Ultra Dockerfile.

The v0.3.0 row is a historical exception: the Nemotron 3 Ultra pairing has no pre-built NeMo RL image that
packages Gym, so it references the `ultra-v3` Dockerfile.

| Bundled NeMo Gym Version | NeMo RL Container / Dockerfile | Recipe |
| --- | --- | --- |
| v0.4.0 | [`nvcr.io/nvidia/nemo-rl:v0.7.0`](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-rl/tags?version=v0.7.0) | [Nemotron 3 Super](/model-recipes/nemotron-3-super) |
| v0.3.0 | [Dockerfile](https://github.com/NVIDIA-NeMo/RL/blob/ultra-v3/docker/Dockerfile) | [Nemotron 3 Ultra](https://github.com/NVIDIA-NeMo/RL/blob/ultra-v3/docs/guides/nemotron-3-ultra.md) |
| v0.2.0 | [`nvcr.io/nvidia/nemo-rl:v0.5.0.nemotron_3_super`](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-rl/tags?version=v0.5.0) | [Nemotron 3 Super](/model-recipes/nemotron-3-super) |
| v0.1.1 | [`nvcr.io/nvidia/nemo-rl:v0.4.0.nemotron_3_nano`](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-rl/tags?version=v0.4.0) | [Nemotron 3 Nano](/model-recipes/nemotron-3-nano) |

<Note>
For end-to-end setup and training instructions, see the [NeMo RL GRPO tutorial](/tutorials/training-tutorials/nemo-rl-grpo).
</Note>

## Unsloth

The NeMo Gym integration with Unsloth is tested on `unsloth==2026.1.4` and `unsloth_zoo==2026.1.4`. Other versions are not guaranteed to work.

<Note>
For setup and training instructions, see the [Unsloth tutorial](/tutorials/training-tutorials/unsloth).
</Note>

---

## VeRL

NeMo Gym 0.2.1+ is compatible with verl pinned to the commit in [`REQUIRED_VERL.txt`](https://github.com/verl-project/verl-recipe/blob/main/nemo_gym/REQUIRED_VERL.txt), tested on the `verlai/verl:vllm017.latest` container (vLLM 0.17.0). Other versions are not guaranteed to work.

<Note>
For setup and training instructions, see the [Training with VeRL tutorial](/tutorials/training-tutorials/verl).
</Note>
