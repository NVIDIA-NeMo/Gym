# Trajectory capability matrix

This matrix is a status snapshot of evidence emitted by current agent paths, not a list of fields
that the schema could theoretically represent. Coverage is path-dependent: an agent can route some
requests through a Gym model server and others directly to a provider.

For the data flow, source-of-truth rules, and join behavior, start with
[Rollout evidence](/main/observability/rollout-evidence).

## How to read the tables

| Status | Meaning |
| --- | --- |
| **Full** | Complete for the evaluated path under the documented observability configuration |
| **Partial** | Some executions or fields are captured; inspect configuration and `ng_trajectory.gaps` before relying on them |
| **Unavailable** | The evaluated producer path does not currently supply this evidence |

Model-server evidence requires `observability_enabled: true`, a shared
`model_call_capture_dir`, and calls routed through a `/ng-rollout/<rollout_id>` Gym model-server
prefix. Direct-provider calls bypass that boundary. Token fields are nullable because providers do
not all report the same usage details.

Agent-side evidence is emitted by harness integrations. Model HTTP capture alone cannot establish
semantic turns, tool execution timing, parallel-tool relationships, or sandbox structure.

## Path-specific caveats

- Simple and LabBench semantic-turn support is partial because verifier responses can omit
  resolution status.
- Other partial values cover CVDP's Simple path, Finance and Remote aggregate usage, LabBench image
  redaction, OSWorld M3 and Pointer direct-provider routes, raised failures omitted by
  Simple-derived agents, and Stirrup calls outside its policy path.
- LabBench rows with `multimodal_history_redacted` omit request and response payload copies from
  `ng_trajectory`.
- OpenClaw coverage includes its standalone resource-server path and the PinchBench sandbox path.
- OpenCode coverage includes its standalone producer and `opencode_sandboxed_agent`; the decoupled
  path composes harness observations with verifier-sandbox evidence returned by the resources
  server.
- Legacy OpenHands retains one cumulative root conversation, so its model-visible history is
  partial. Its pinned fork does not route calls through a rollout-prefixed Gym model-server endpoint.
- Aggregate-metrics requests omit `ng_trajectory`, `ng_model_call_capture`, and
  `ng_agent_observations` attachments.

## Maintenance contract

This snapshot was validated against `main` on 2026-09-02. A change to an agent producer, model-call
routing path, or trajectory projection must update the affected row and its integration test in the
same pull request. The Gym observability maintainers review the matrix against those executable
producer tests; schema support by itself is not sufficient to mark a cell **Full**.
