Compare harnesses against scripted model, tool, and verifier scenarios.
Each P0, P1, or P2 column reports **passing scenarios / measured scenarios** for
that priority tier. A scenario counts in a tier only when it has applicable checks
at that priority, and passes when all of those checks pass. A scenario can contribute
to more than one tier; failures in one tier do not change another tier's count.
A dash means no applicable measurements are available. All current checks are P0.

Completed check results remain visible when a probe reports execution errors.
The detailed tables and linked CI results show the individual failures.

The checks cover local execution. Remote sandboxes, agent sessions, multimodal
inputs, compaction, and parallel execution require separate qualification.
See [Harness Conformance](/main/observability/harness-conformance) for the contracts
and [Rollout Evidence](/main/observability/rollout-evidence) for collection setup.
