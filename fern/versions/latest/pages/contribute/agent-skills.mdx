Point an AI coding assistant at this repository and it can follow Gym's endorsed workflows — adding a benchmark, debugging a failed run, or editing these docs — without guessing.

No extra install: clone Gym, then ask in plain language (for example, "add a new benchmark" or "debug this rollout failure").

<Tip>
Adding a benchmark? Humans start at the [onboarding decision tree](/contribute/environments/onboarding-decision-tree). Assistants should follow [`.agents/skills/add-benchmark`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills/add-benchmark) — copy an existing overlay first; add a new scorer only when nothing can grade the task.
</Tip>

## Where skills live

One source of truth: [`.agents/skills/`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills). Claude Code and Codex use the same files through [`.claude/skills/`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.claude/skills) and [`.codex/skills/`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.codex/skills), so copies cannot drift.

## Available skills

| Skill | Use it when you want to |
|---|---|
| [`add-benchmark`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills/add-benchmark) | Add a benchmark overlay or a new scorer |
| [`nemo-gym-reward-profiling`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills/nemo-gym-reward-profiling) | Run `gym eval run` / `gym eval profile` and inspect scores |
| [`nemo-gym-debugging`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills/nemo-gym-debugging) | Diagnose empty JSONL, scorer errors, or stuck jobs |
| [`nemo-gym-docs`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills/nemo-gym-docs) | Add, move, or remove pages on this docs site |
| [`nemo-gym-blade-analysis`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills/nemo-gym-blade-analysis) | Write a BLADE-style report from rollout files |
| [`nemo-gym-pivot-datasets`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills/nemo-gym-pivot-datasets) | Build training/eval rows from rollout files |
| [`gh-stack`](https://github.com/NVIDIA-NeMo/Gym/tree/main/.agents/skills/gh-stack) | Stack pull requests with the `gh-stack` CLI |

To pin a playbook instead of relying on auto-discovery:

```text
Follow .agents/skills/add-benchmark/SKILL.md to integrate this benchmark.
```
