<Info>
**Before you choose a path:** complete [Development Setup](/contribute/development-setup) and the [Quickstart](/get-started/quickstart) (`env.yaml` with model credentials).

**1.** Search existing scorers · **2.** Pick overlay, new server, or harness · **3.** Follow the linked guide
</Info>

An **environment** is the measurement surface: tasks, verifier, tools, and state. A **benchmark** is a versioned eval on top of that surface — usually a new dataset, prompt, and `prepare.py`, not a new server.

Search the catalog before you create anything. A bare `gym search "…"` queries the **environments** catalog, not scorers:

```bash
gym search resources-servers "grade school math"
gym list resources-servers
gym search benchmarks math
```

Then pick the row that matches what you actually need to add:

| You need | You create | Start here |
| --- | --- | --- |
| Same scorer, new data / prompt / split | Overlay under `benchmarks/<name>/` | [Add a benchmark](/contribute/environments/adding-a-benchmark) |
| New `verify()`, tools, or session state | Resources server under `resources_servers/<name>/` | [New Environment](/contribute/environments/new-environment) |
| New agent loop, GUI, sandbox, or third-party runner | Agent server or a library wrap | [Complex benchmarks](/contribute/environments/adding-a-benchmark#complex-benchmarks) |

<Cards>
  <Card title="Reuse a scorer" href="/contribute/environments/adding-a-benchmark">
    Copy `benchmarks/gsm8k` (math), `benchmarks/gpqa` (multiple choice), or `benchmarks/livecodebench/v5_2408_2502` (code). No `app.py`.

    <Badge intent="success" minimal outlined>most common</Badge>
  </Card>
  <Card title="Create a new scorer" href="/contribute/environments/new-environment">
    Scaffold a resources server, implement `verify()`, and satisfy the five-row CI gate.

    <Badge minimal outlined>new resources server</Badge>
  </Card>
  <Card title="New harness or wrap a library" href="/environment-tutorials/integrate-external-environments">
    The scorer already exists, but the episode is driven by a different agent or an external benchmark runner.

    <Badge minimal outlined>advanced</Badge>
  </Card>
</Cards>

<Note>
Still unsure? If an existing resources server can grade the task, it is an overlay. Only scaffold `resources_servers/` when you must change how the reward is computed.
</Note>
