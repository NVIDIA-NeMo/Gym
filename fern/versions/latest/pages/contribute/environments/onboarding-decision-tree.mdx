<Info>
You have a benchmark to contribute. First decide whether Gym already has a **scorer** — the program that grades the model's answer.

**Before you start:** [Development Setup](/contribute/development-setup) and the [Quickstart](/get-started/quickstart) (create root `env.yaml` with your model API key).
</Info>

A **scorer** lives under `resources_servers/` and implements `verify()`. An **overlay** is a folder under `benchmarks/` that reuses a scorer (new dataset and prompt; no new scoring code). Gym's default agent is `simple_agent` (one turn, no GUI or sandbox).

Search for an existing scorer. A bare `gym search "…"` searches environments, not scorers — include the type:

```bash
gym search resources-servers "grade school math"
gym list resources-servers
gym search benchmarks math
```

Pick the row that matches what you need to add, then open that guide:

| You need | You create | Open this guide |
| --- | --- | --- |
| Same scorer, new dataset | Folder under `benchmarks/` | [Add a benchmark](/contribute/environments/adding-a-benchmark) |
| New scoring code | Folder under `resources_servers/` | [New Environment](/contribute/environments/new-environment) |
| GUI, sandbox, or external runner | A different agent, or wrap a library | [Complex benchmarks](/contribute/environments/adding-a-benchmark#complex-benchmarks) |

<Note>
If an existing scorer can grade the task, add an overlay. Create a new resources server only when you must change how the score is computed.
</Note>
