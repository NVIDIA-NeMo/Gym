<Info>
A **scorer** (resources server) grades the model's answer. A **benchmark** is usually a new dataset and prompt on top of an existing scorer, not new scoring code. Most contributions copy a folder under `benchmarks/` and never write `app.py`.
</Info>

<Tip>
[Development Setup](/contribute/development-setup) first (`uv sync`, `pre-commit install`, `git commit -s`). Using an AI assistant? See [Agent Skills](/contribute/agent-skills).
</Tip>
