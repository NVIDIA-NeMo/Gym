<Info>
**Environment** = tasks, verifier, tools, and state. **Benchmark** = a versioned eval overlay on that surface (dataset, prompt, `prepare.py`). Most contributions reuse a scorer and never touch `app.py`.
</Info>

<Tip>
Complete [Development Setup](/contribute/development-setup) first. Using Cursor, Claude Code, or Codex? Follow the [`add-benchmark`](/contribute/agent-skills) skill.
</Tip>

Read the decision tree first, then the matching how-to. Keep the [Single-step tutorial](/environment-tutorials/single-step-environment) for a hands-on `verify()` walkthrough.
