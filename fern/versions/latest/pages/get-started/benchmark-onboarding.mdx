## Validation scope

Read these dimensions independently. A fixture pass is not a real-model rollout, a parity study,
or proof of complete traces. The adapters remain experimental until their declared acceptance checks pass.

| Recipe | Structural | Runtime | Parity | Trace |
| --- | --- | --- | --- | --- |
| Native exact-answer control | Scaffold and verifier tests included | One-sample real-model smoke passed; lifecycle acceptance still limited | Control only; no benchmark claim | Smoke health unobserved without captures; not trace acceptance |
| Harbor local task | Task, oracle and negative verifier tests included | Real Docker/model acceptance pending | Not established | Native Harbor artifacts; canonical Gym trace unavailable |
| Legacy Verifiers local environment | Local environment and conversion tests included | Corrected rubric passed one-sample real-model smoke (v0); lifecycle acceptance still limited | Not established; not current Hub v1 support | Adapter output only; canonical Gym trace unavailable |

For a new benchmark, preserve dataset/split, prompt, agent, model, image, resource, timeout and verifier
identity. Keep raw artifacts and separately report execution failures, valid zero scores and missing evidence.
See [benchmark contribution guidance](/main/contribute/environments/adding-a-benchmark) and
[rollout health](/main/evaluation/rollout-health). Health checks report evidence; they do not certify completion.
