# Description

ERPBench-100: 100 stateful enterprise-operations tasks over 52 tools; SQLite-backed business systems with transactional writes and a full call trace; graded by a deterministic state-and-trace verifier with no LLM judge.

Each task drops the policy into an isolated company: 52 tools such as `erpbench__get_task, erpbench__get_decision, erpbench__get_submission, erpbench__record_decision, erpbench__submit_answer, oracle_fusion__items__list`,
one assignment written the way a manager would write it, and world state that persists across the
episode. Grading is deterministic: the package's own verifier scores the final state and the call
trace (outcome, required investigation before writes, readbacks, containment of unrelated records).
Reward is the criterion fraction (`reward_mode: gated` scales it by the earned share of the
suite's outcome families); `strict_pass` requires every criterion and is rare by design, so the
dense fraction is the training signal.

# Example usage

Create an `env.yaml` in the Gym root with `policy_base_url`, `policy_model_name`, `policy_api_key`,
and `hf_token` (the train and validation splits resolve from Hugging Face).

## Getting the task packages

```bash
harbor datasets download blobfishai/erpbench-100-suite -o data/suites/erpbench-100-suite
export BLOBFISH_ERPBENCH_100_DIR=$PWD/data/suites/erpbench-100-suite/erpbench-100-suite   # optional; this is the config default
```

Packages are executable code run in-process by the server; `data/suite_manifest.json` pins each
one to its reviewed SHA-256 and the server refuses to start on anything else.

## Running servers

```bash
gym env start --environment blobfish_erpbench_100 --model-type openai_model
```

## Collecting rollouts

```bash
gym eval run --no-serve --agent blobfish_erpbench_100_simple_agent     --input environments/blobfish_erpbench_100/data/example.jsonl     --output results/blobfish_erpbench_100_example_rollouts.jsonl --num-repeats 1
```

`data/example.jsonl` carries 5 validation rows; `data/example_rollouts.jsonl` is one
DeepSeek rollout per example row.
